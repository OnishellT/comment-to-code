# ADR 0008: Count evidenced failed repairs as repeated mistakes

Status: implemented review-driven correction, issue29;3 targeted regressions and66 narrow checks pass. Independent final review, native and complete-history acceptance remain pending.

## Evidence

The owner explicitly selected count_failed_repairs. Fresh substantive feedback after an attempted same-cause code fix is another mistake, even while completing one repair. This supersedes the independent-original-defects-only convention in ADR0001/0003/0005/0006, not the threshold of two or causal evidence requirements. Frozen Reel PR146 contains initial title feedback, a partial title fix and fresh feedback on remaining error paths; duplicate inline/review reports of the same post-fix state still count once. Historical strict-old-contract audits do not establish acceptance of all53 proposals: unrelated mechanisms, over-prescribed remedies and provenance defects remain material.

## Decision

Change only consolidation policy/context and conservative same-thread canonicalization. Supply each admitted member's original comment body, kind, creation time, thread/path and originalCommitId once alongside the complete catalog/current findings. Diff hunks are code artifacts, not global metadata: supply them and noneligible same-thread/PR review-discussion context only for current-delta PRs. Deduplicate their actual source/patch artifacts into shared per-PR tables, including cross-file fixes and pathless reviews. Available empty source has a real equality fingerprint; unavailable source has none. Do not truncate; the existing input budget applies before every call. Keep v6 classification, citation feedback, finding hashes, capture/output/checkpoint schemas and resource/privacy boundaries unchanged. Changed grouping instructions/context naturally invalidate prior grouping state without modifying historical caches.

Supply complete captured source/patch tables only for PRs represented by the CURRENT delta, including every captured earlier version and cross-file/pathless review evidence. Keep all original member commentary and each original finding's cause/prevention/resolution/evidence in the complete catalog. Finished PRs retain metadata, not repeatedly transmitted full code. codeContext states this boundary explicitly: consolidation is not a new full-code review of every old PR. The private all-PR fingerprint/anchor index still serves batch, restore and final canonicalization. If active PR evidence plus complete catalog/commentary cannot fit, fail before the call without truncation or an automatic limit increase; the16MiB adapter ceiling is not a model-context promise.

An occurrence may be an original defect or fresh substantive feedback after an evidenced relevant attempted repair. A new PR/thread/time/SHA, unrelated change, unchanged repost, acknowledgement or duplicate review is not another mistake. One minimal preventive invariant must explain every occurrence and its accepted observed resolution. Explain the original/failed-repair distinction and evidence rather than inferring a repair from chronology alone.

A captured originalCommitId can remain the old anchor on a fresh reply, not identify the current reviewed version. Corroborate available original source against its hunk, then compare captured PR code artifacts, including delegated files visible only through commit patches. An unchanged caller cannot certify an unchanged causal state, and retaining an old hunk does not disprove an additive repair. Equal-time reports with matching complete observed artifact sets take priority over other differing pairs in model-mixed incidents. Incomplete/unverifiable context cannot add an occurrence or bridge corroborated stages. Ordered feedback and comparable PR code changes only permit a split; they do not identify a relevant attempt or bind an old anchor to a new version. Model assignments/explanations must establish actual relevant attempt, fresh feedback, current-state linkage and accepted resolution from original commentary and captured changes. Ambiguous retained anchors therefore defer to supported model lineage, not an equality veto; universal mechanical duplicate ceilings are not claimed there. An intentionally semantically wrong split cannot always be rejected mechanically: no hash, original anchor or witness field is a semantic gate. Missing/squashed commits and misleading author dates are not mandatory temporal certificates; missing current-state linkage must not be invented.

Keep exact target partition, snapshot-index references, paired refinement, collision checks, whole-batch atomic checkpoints, final coverage and two-supported-occurrence threshold. No temporal framework, handwritten classifications, cache edits, new options, provider calls or main merge.

Actual review reproduced additive-repair suppression by whole-source substring containment and inflation when any differing anchor overrode an exact-stage overlap. Parent independently reproduced a delegated repair with unchanged caller snapshots and actual before/partial/final policy patches. Correct these together without a new incident/proof schema, body parsing, extension rules, provider features or weakened literal/coverage guards; keep the raw failing consumer evidence. Model-controlled unrelated-change regressions must retain one occurrence rather than asserting that equality of the commented window can establish semantic irrelevance.
